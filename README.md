# 🫦 Twitch Chat Stats

## 🌐 Сайт

Сайт показывает:

* 🏆 общий топ кусей;
* 🍑 топ попок;
* 📅 расписание;
* 🎖️ достижения;
* 🖤 чат с lilanei;
* 🔎 поиск по нику, цели или сообщению;
* 📂 подробности по каждой записи.

## 🔐 Twitch вход

На сайте есть вход через Twitch.

После входа сайт может:

* показывать ник пользователя;
* подсвечивать пользователя в топе;
* сохранять достижения;
* открывать вкладку достижений;
* использовать ник пользователя на странице lilanei.
