# 🫦 Топ попок — GitHub Pages сайт

Это простой статический сайт: `index.html` + `style.css` + `script.js`.

## Как обновить данные

1. В парсере скачай файл **🌐 JSON для сайта**.
2. Замени им файл:

```text
data/popki_site_data.json
```

3. Загрузи изменения на GitHub.

## Как включить GitHub Pages

В репозитории GitHub:

```text
Settings → Pages → Build and deployment → Source: Deploy from a branch
Branch: main
Folder: /root
Save
```

Главный файл сайта — `index.html`.
